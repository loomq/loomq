## 2. 失败测试

### 2.1 `BugNullPrecisionTierNormalizationTest`

- 场景：创建 Intent 时 `setPrecisionTier(null)`。
- 期望：内部 live Intent 的 `precisionTier` 被归一化为默认档。
- 修复前：内部仍为 null。

### 2.2 `BugFactoryNullPropertiesTest`

- 场景：`LoomqEngineFactory.createFromProperties(null)`。
- 期望：不抛异常。
- 修复前：NPE。

### 2.3 `BugReadOnlyViewCloseTest`

- 场景：对 `ReadOnlyIntentStoreView` 调用 `close()`。
- 期望：no-op。
- 修复前：抛 `UnsupportedOperationException`。

---

## 3. 修复设计

### 3.1 null `precisionTier` 归一化

**文件**：`IntentCommandService`

新增：

```java
private void normalizePrecisionTier(Intent intent) {
    if (intent.getPrecisionTier() == null) {
        intent.setPrecisionTier(precisionTierCatalog.defaultTier());
    }
}
```

调用点：

- `createIntent`：validate 后立即归一化；
- `createIntents`：在主循环保存旧值快照后、`transitionTo` 前归一化；
- `updateIntent`：updater 后、`IntentValidator.validate` 前归一化。

同时修复 `IntentCommandService` 构造器中 `precisionTierCatalog` 可能为 null 的问题：

```java
this.precisionTierCatalog = config.precisionTierCatalog() != null
    ? config.precisionTierCatalog()
    : PrecisionTierCatalog.defaultCatalog();
```

### 3.2 `createIntents` 回滚恢复 `precisionTier`

**文件**：`IntentCommandService`

- 新增 `PrecisionTier[] oldTiers`；
- 在修改 `precisionTier` 前保存旧值；
- 回滚时先 `setPrecisionTier(oldTiers[i])`，再 `rollbackStatus(...)`，避免 `setPrecisionTier` 污染 `updatedAt`。

### 3.3 `LoomqEngineFactory` null 防御

**文件**：`LoomqEngineFactory`

```java
if (props == null) {
    props = new Properties();
}
```

### 3.4 `ReadOnlyIntentStoreView.close()` no-op

**文件**：`ReadOnlyIntentStoreView`

```java
@Override
public void close() {
    // no-op
}
```

### 3.5 `IntentTraceStore` 文档修正

**文件**：`IntentTraceStore`

将类注释中的 `LRU eviction` 改为 `FIFO eviction`。
